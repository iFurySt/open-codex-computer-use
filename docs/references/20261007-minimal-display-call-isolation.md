# 最小显示器复现：调用方式与周期请求隔离

## 结论与边界

71 行 demo 已足以触发 LG 条件下的持续请求累积，但它调用的私有显示器实现及系统服务不在这 71 行内。本轮进一步把现象缩到显示拓扑接入/移除后增加的约 5.05 秒周期请求流。尚未获得 root ColorSync 服务的调用栈，不能认定具体漏注册函数、计时器对象或责任进程，也未发现经过验证的根因修复。

用户物理断开重连后报告恢复顺畅；随后测得 ColorSync 两服务合计约 1.41% 单核 CPU、0.198 请求每秒。146 份 ICC 内容与上一轮 30 次测试基线完全相同，因此恢复不要求删除这些 ICC 文件。此次未采集用户操作瞬间，不能指定重连中的哪个内部步骤清除了异常。

## 四次有界对照

环境为 macOS 26.5.1 arm64，内置屏与 LG 连接。固定已预热身份，不修改色度、布局或系统偏好。每段约 20 秒。CPU 为两个 ColorSync 服务区间 CPU 时间合计，100% 表示占用一个核心。

| 对照 | 基线 CPU / 请求每秒 | 在线 CPU / 请求每秒 | 退出并移除后 CPU / 请求每秒 |
| --- | --- | --- | --- |
| 仅改全局高优先级队列 | 1.34 / 0.238 | 3.73 / 0.381 | 4.15 / 0.619 |
| 仅改 typed init 调用 | 3.73 / 0.573 | 7.94 / 0.793 | 6.36 / 0.998 |
| 原 demo 持有 60 秒 | 6.23 / 0.950 | 11.25、12.19、10.98 / 1.141、1.242、1.145 | 8.49 / 1.339 |
| 原 demo + 仅 CoreGraphics 观测 | 9.34 / 1.391 | 16.48 / 1.600 | 12.09 / 1.905 |

这是顺序增量对照；只有第一项前为恢复后的健康基线。每项只有一次创建，不能当作候选间的独立统计比较。四次 helper 均退出、显示器均从系统列表消失；物理拓扑和所有 ICC 内容保持不变。

- 全局队列来自 [Chromium 实现的配置参考](https://chromium.googlesource.com/chromium/src/+/HEAD/ui/display/mac/test/virtual_display_util_mac.mm)，没有解决增量。该参考的移除超时 workaround 也不等同 ColorSync 修复，未采用额外热插拔。
- typed init 使用正确 method family 和 unsigned int 宽高声明，排查动态 objc_msgSend 的 ARC/ABI 差异，仍有增量。未证明原调用发生内存错误。
- 同一对象保持在线、不重新 apply 时，三个观察窗口未见请求持续阶梯增加；退出后反而增加。支持拓扑事件触发而非每帧捕获不断生成请求的方向。
- 新观测探针只用公共 CoreGraphics/Foundation，不链接 SCK/Metal/AppKit，也不调用权限查询。仍有增量，排除旧观测探针框架初始化为必要条件。其他已有 runtime 未隔离，不能据此排除所有系统消费者。

## 周期性证据

三次后约 45 秒日志有 63 次请求，最佳重复间隔 5.053 秒，55/55 个可比较的后续周期请求误差小于 10ms；按 20ms 相位容差分为 7 组，每组 9 次。

四次后同等观察有 79 次请求，间隔 5.052 秒，55/70 对误差小于 10ms，分为 9 组，组内 8–9 次。与健康状态约每五秒一组、每次接入/移除新增两组的模型吻合，属于推断。日志相位组不是已证明的计时器数量，也不能识别发送方 PID。分析器在 4.8–5.3 秒范围搜索，属于针对该现象的检验，并非通用周期发现器。

## 消费者与权限隔离

系统设置 Displays 扩展的用户态 sample 主要是 SwiftUI/图像解码，没有给出 ColorSync 请求来源。转到 General 后仍 11.40% / 1.775 请求每秒；正常退出系统设置及其扩展后仍 12.35% / 1.711。退出没有清除周期请求，不能归因于该 UI 当前持有显示器列表。随后恢复原 Displays 页面及内置屏查看项，未改变显示偏好。

root 服务 sample 被当前用户权限拒绝。已请求用户在终端执行只读管理员 sample，密码不进入聊天；目前待结果。其他 worktree runtime 保留，未获授权强制结束，日志请求用户上下文字段不能当作发送 PID。

## 工具、验证与下一步

脱敏数据：`experiments/DisplayPerformance/results-call-isolation-20261007.json`。外部 scratch 候选由 `build_minimal_variant.py` 生成并记录源/二进制哈希，global/typed 候选经 Developer ID 签名；没有替换生产实现。`held.py` 负责单次持有和退出验证，`CoreGraphicsProbe.m` 负责纯 CG 观测，`periodicity.py` 处理本地日志。离线 Python 测试 23 项通过。
