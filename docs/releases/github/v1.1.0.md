## What's Changed

* Added macOS Locked Use: enable it with `ocu locked-use enable` to install signed components, grant permissions, and continue GUI automation behind display shields while your Mac is locked. Tasks relock the Mac before removing the shields.
* Added targeted accessibility queries with `app.query()` and structured permission checks with `ocu doctor --json`.
* Added persistent screenshot settings with `ocu config`, including PNG, JPG, and WebP output.

**Full Changelog**: https://github.com/iFurySt/open-codex-computer-use/compare/v1.0.0...v1.1.0
