### 🧠 Design Intent (Why)
有些操作应用已经暴露成 App Intent，用界面把流程点一遍既慢又脆。按身份执行不依赖窗口可见或在前台。

macOS 没有免 entitlement 直接触发 App Intent 的 API：私有 LinkServices executor 会拒绝未经校验的调用方。唯一受支持的路径是 Shortcuts——App Intent 在 workflow 里的 action identifier 恰好就是 `<bundle id>.<intent name>`，所以生成一个只含该 action 的 shortcut 就够了，不需要额外的绑定表。

stdin 必须显式接 `/dev/null`：`shortcuts` 在 stdin 仍然挂着时会去读它，那会吃掉运行时自己的管道。

**安全取向**：这个 tool 扩大了能力边界，因此把限制做在最窄处——只跑应用自己的 intent，安装必须由用户点一次确认，identifier 严格校验以保证不会有 `/` 或 `..` 落到文件名上。相关约束已写入 `docs/SECURITY.md`。
