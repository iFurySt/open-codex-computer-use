# v1.1.2 release

## 用户诉求

按发布 SOP 增加一个小版本，跟踪所有发布目标完成，最后使用 `npm i -g open-computer-use` 更新本机并确认最新版本与基本功能。

## 改动

- 从最新 main 准备补丁版 1.1.2，同步 plugin manifest、Swift/Go runtime、smoke、测试和示例版本。
- 准备英文 GitHub Release notes 与用户发布记录，交付移动窗口光标跟随、Linux 动作回读配置，以及改名后的仓库 / npm 元信息。
- 保留既有 npm 包名、CLI alias、App Bundle ID 与签名团队；同步 CI/CD 文档中正式制品必须包含 Apple 签名组件的现行要求。

- Swift 351 项（8 项跳过、0 失败），包含真实 AX 窗口跟随回归；Node 40 项、Linux Python 14 项、Locked Use Python 31 项和 Windows / CLI Go 测试通过。
- 文档骨架、Action SHA 固定、英文 Release notes 与签名 keychain mock 回归通过。
- Developer ID universal App 与四个 Locked Use 组件签名 / 架构检查通过，remote 插件 ABI 与 kernel verifier 正负例通过。
- 三个 npm staging 包及 tgz 均为 1.1.2，包含六个 runtime target、四个 alias，无 optionalDependencies；主 App、Guardian 与插件版本均为 1.1.2。
- CursorMotion-1.1.2.dmg 的 universal 架构、签名与磁盘镜像校验通过；直接下载归档与 SHA256SUMS 全部匹配。
