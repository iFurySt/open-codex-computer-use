# Locked Use

Configuration lives at `/Library/Application Support/OpenComputerUse/LockedUse/configuration.json`. Installation creates:

```json
{
  "schemaVersion": 1,
  "enabled": true
}
```

Editing this file requires administrator privileges. Changes take effect when the service restarts. Validation records are generated by the app; you do not need to fill them in. Changing `enabled` alone does not install the components or complete production validation.

## Configure from the CLI

Locked Use requires a separate installation. OCU's permission setup does not enable it automatically. Run these commands while your desktop is unlocked and complete the administrator prompt:

```bash
# Install and enable validation mode; use this for testing for now
ocu locked-use enable --validation

# Check installation, permissions, and validation status
ocu locked-use status

# Disable and uninstall, restoring the original system lock-screen policy
ocu locked-use disable
```

Use a signed app that includes the Locked Use components. For a source build, set `OPEN_COMPUTER_USE_INCLUDE_LOCKED_USE=1`. The main app needs Accessibility and Screen Recording permissions. Guardian also needs Accessibility and Input Monitoring. After installation, request Guardian's permissions with:

```bash
"/Library/Application Support/OpenComputerUse/LockedUse/OCU Guardian.app/Contents/MacOS/OCUGuardian" --request-permissions
```

Production mode requires full validation, which is still incomplete. Running `enable` without `--validation` installs production mode, but automatic unlock remains unavailable without valid validation records.

## Configuration and commands

| Setting / action | Meaning | Command |
| --- | --- | --- |
| `schemaVersion` | Configuration format version; always `1` | Generated during installation; no separate setter |
| `enabled` | `true` after installation; disabling removes the configuration file | `ocu locked-use enable` / `ocu locked-use disable` |
| `validatedOSBuild` | Validated macOS build; omitted before validation | Generated by `ocu locked-use certify` after validation passes |
| `validatedBrokerHash` | Validated service hash; omitted before validation | Same as above |
| `validatedGuardianHash` | Validated Guardian hash; omitted before validation | Same as above |
| `validatedPluginHash` | Validated authorization plug-in hash; omitted before validation | Same as above |
| Install validation mode | For local development and testing | `ocu locked-use enable --validation` |
| Check status | Installation, permissions, and validation status | `ocu locked-use status`; add `--json` for JSON output |
| Open settings | Choose to enable production mode or disable | `ocu locked-use settings` |
| Recover installation | Recover an incomplete installation and remove its components | `ocu locked-use recover` |
| Validate production mode | Review complete test records and confirm; switch to production mode if requirements are met | `ocu locked-use certify` |
